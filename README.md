# get_dp_health
Get Virtual Solar Observatory Data Provider status via an API. Both POST and GET
methods are supported, also a small test web page allows access to the API.

It is assumed that uv is installed and pinned to a recent version of Python.

To run this :

* Clone the repo and cd into the top level
* Run the ```setup_uv.sh``` script
* Run the ```start_server.sh``` script. It will tell you what URL is being served out.
* Point a browser at the URL

At the URL you can try things yourself, or follow he link to the API documentation.
